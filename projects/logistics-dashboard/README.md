# Logistics Operations Dashboard

## Business Problem
A logistics company wants to monitor delivery performance, identify delays
and returns, and track cash-on-delivery (COD) amounts across major cities.

The objective is to create a simple Excel dashboard that helps operations
teams quickly assess performance and take action.

---

## Dataset
The dataset contains order-level logistics data, including:
- City
- Delivery time (hours)
- Delivery status
- COD amount

---

## Tools Used
- Excel (data cleaning, pivot tables, dashboard)
